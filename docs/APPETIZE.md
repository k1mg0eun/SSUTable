# Appetize로 앱 보기

에뮬레이터나 안드로이드 폰 없이, 브라우저에서 SSUTable을 실제로 돌려 보는 방법이다.
[Appetize](https://appetize.io)는 클라우드에 있는 안드로이드 폰에서 APK를 실행하고 화면을 브라우저로 보여 준다.
앱은 Firebase에 그대로 붙으므로, 여기서 예약하면 실제 DB에 기록되고 다른 폰에도 보인다.

## 1. 공유 링크로 바로 보기 (가입 필요 없음)

김고은이 올려 둔 빌드를 링크로 연다. 링크는 팀 단톡방에 공유한다(공개 저장소라 여기에는 적지 않는다).

1. 링크를 연다.
2. 폰 화면의 **Tap to Start**를 누른다. 몇 초 뒤 앱이 뜬다.
3. 마우스 클릭이 터치로 들어간다. 글자는 키보드로 입력하면 된다.
4. 다 봤으면 탭을 닫는다.

주의할 점
- 공유 링크 사용 시간은 **올린 사람 계정의 무료 시간(한 달 30분)에서 빠진다.** 셋이 같이 쓰면 금방 끝나니 길게 볼 땐 2번 방법을 쓴다.
- 공유 링크는 **그 빌드에만** 묶여 있다. 새 APK를 올리면 링크가 바뀌므로 단톡방 링크도 새로 공유해야 한다.

## 2. 내 계정에 직접 올려서 보기

각자 무료 계정을 만들면 사람마다 한 달 30분씩 쓸 수 있다.

1. APK 만들기

   ```bash
   cd SSUTable && ./gradlew :app:assembleDebug
   ```

   결과물: `app/build/outputs/apk/debug/app-debug.apk`

2. https://appetize.io 에서 Google이나 GitHub 계정으로 가입·로그인한다.
3. **Upload App** → 위 APK를 끌어다 놓는다.
4. 업로드가 끝나면 **Start** → **Tap to Start**.

같은 패키지(`com.g1j2.ssutable`)로 다시 올리면 기존 앱이 새 빌드로 바뀐다.

## 둘러보기 순서

1. **첫 실행**: 권한 안내 → 시작하기. 권한은 허용·거부 모두 괜찮다. 이름과 학번은 아무거나 넣는다.
2. **홈**: 지금 모드와 혼잡도가 보인다. 상단에 "오프라인" 표시가 없으면 Firebase에 연결된 것이다.
3. **좌석 탭**: 빈자리 → 예약하기 → 예약 완료. 식사 모드면 식권 QR도 나온다.
4. **설정 → 시연 모드**: 시각 옮기기 `11:15`, 배속 `10배`로 두면 30초쯤 뒤 점심 모드로 바뀐다. 아침·점심·스터디 모두 340석이 다 열린다.
5. **정리**: 둘러본 뒤 설정의 **모든 좌석 예약 초기화**를 눌러 실제 DB에 남은 좌석 기록을 지운다. 시각 옮기기는 **지금**, 배속은 **1배**, 모드 지정은 **자동**으로 되돌린다. 시연 설정은 모든 폰이 공유하므로 꼭 되돌려 둔다.

## 알아 둘 것

- Appetize에서는 한 번에 한 대만 띄울 수 있어서 **두 폰 동기화는 볼 수 없다.** 두 폰 확인은 README의 "두 폰 확인 체크리스트"를 실제 폰 두 대로 한다. Appetize 한 대 + 실제 폰 한 대 조합은 가능하다.
- 위치는 가상 폰이라 실제 GPS가 아니다. 도착·이탈은 지금처럼 설정의 `시연용 위치` 스위치로 바꾼다.
- 무료 계정은 세션 하나가 몇 분 지나면 끊길 수 있다. 끊기면 다시 Start를 누르면 된다.
